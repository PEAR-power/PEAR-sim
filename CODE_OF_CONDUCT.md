# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work rather than people,
and keep discussions technical. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainers through
[GitHub private vulnerability reporting](https://github.com/PEAR-power/pear-sim/security/advisories/new)
(choose it even though the report is not a vulnerability) or to a maintainer
directly. Reports are handled confidentially.
