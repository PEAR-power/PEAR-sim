# pear-sim-mcp

<!-- mcp-name: io.github.PEAR-power/pear-sim -->

Starts the [PEARSim](https://github.com/PEAR-power/pear-sim) MCP server:

```bash
uvx pear-sim-mcp
```

This package contains no code. It installs `pear-sim` with its MCP extra and
provides the `pear-sim-mcp` command; see the main project for documentation.
